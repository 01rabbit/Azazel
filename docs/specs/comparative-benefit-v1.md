# Comparative defensive benefit v1

Owner: [Azazel#67](https://github.com/01rabbit/Azazel/issues/67).
Status: executable-analysis specification; no measured product-superiority claim.
Implementation belongs to [Edge#393](https://github.com/01rabbit/Azazel-Edge/issues/393),
not this doctrine repository. Edge supplies the offline
`azazel_edge.benchmark.benefit` analyzer and `benefit_receipt` capture adapter.

## Freeze before running

Register an immutable experiment identifier, primary claim and metrics, common
observation horizon, corpus/split hashes, policy/configuration hashes, exact
repository commits, package/model/runtime versions, environmental resource
budgets, assignments/order/seeds, supported-feature matrix, ground-truth method,
practical-benefit threshold, service-cost non-inferiority margins, sample-size
plan, stopping/exclusion/multiplicity rules and safety teardown plan. Publish or
independently retain the registration digest before held-out data collection.
A manifest/receipt digest alone is not proof that registration happened earlier.

Use separate versions for calibration/pilot and confirmatory held-out cases.
Changed prompts, features, thresholds or configurations produce a new candidate
and a new holdout. Include all assigned runs, crashes, missing observations and
protocol deviations. Record unsuccessful configurations; never silently drop
them from denominators.

## Comparator matrix

| ID | Configuration | Required comparison discipline |
| --- | --- | --- |
| C0 | Observe only | Workload/capture reference, isolated targets only |
| C1 | Immediate bounded deterministic block/contain | Legitimate best outcome even when no progression occurs |
| C2 | Current fixed delay/redirect | Same verified provider, actual applied scope |
| C3 | Coherent static deception | Same exposure/time/resource budget |
| C4 | Strong generic local AI/RAG advisory | Same evidence, knowledge and model/compute allowance |
| C5 | Delivered Azazel candidate | Declared implemented features only |
| C6 | Independent external defensive reference | Frozen upstream commit/dependencies/config, actual executed adapter |

Two tracks are separate: common supported capabilities with comparable input
visibility/compute; and declared field constraints such as WAN loss and finite
memory. Report unsupported capabilities as scope, not invented execution
failures. Preserve third-party source and license notices. Without an executed
C6 arm no claim to outperform that implementation is permitted. An internal
baseline result may still be published with its narrower scope.

Randomize paired execution order, verify clean reset and equivalent starting
state, and keep the legitimate background workload fixed. Replay cannot prove
that an attacker adapted to a changed defense; those claims require an isolated
interactive closed-loop scenario and independently recorded progression.

## Evidence bundle

A frozen manifest (`azazel-benefit-experiment/v1`) declares arms, source and
configuration identities, horizon, analysis plan and pair/arm/scenario/seed/order
assignments. Every assigned run receives an immutable ledger position. Captures
retain monotonic clock and boot scope, independent protected-goal milestones,
legitimate-service transactions including timeouts, safety observations,
provider/decision/mechanism/release evidence, resource/fault observations and
capture coverage. Bind normalized receipts to the manifest digest and retain the
original captures for source verification.

The Edge analyzer's first slice measures protected-objective completion,
restricted time to progression through a common horizon, paired legitimate p95
latency/error-rate changes and safety violations. A no-goal observation is
censored at H only when the full H is verified; earlier loss remains missing.
It reports paired differences and deterministic bootstrap intervals; small pilot
intervals are descriptive, not a substitute for a power/sample-unit review.

Additional independently scored questions/evidence value, resource/fault metrics,
clock uncertainty, Knowledge/canary/model ablations and operator decisions remain
explicit fields in the registered study and their owning product evidence. The
analyzer does not synthesize those results from an alert, hash or AI narrative.

## Operator study

Compare current UI, new UI without MIO, deterministic guidance, and independently
admitted model advice where available. Use identical cases/permissions,
counterbalanced order, held-out cases and blinded fixed-rubric scoring. Include
stale/absent observations, planned-versus-applied actions, wrong persuasive
advice and a harmless case requiring no intervention. Measure correctness and
unsafe choices before time-to-correct-answer, workload and handoff completeness.
Two reviewers locating a card in ten seconds is a layout smoke test, not efficacy.

## Decision and stop rules

Unauthorized action, decoy escape to protected assets, accepted forged evidence
or advisory-to-authority conversion fails safety and stops the relevant live lab
arm. Service/resource budgets are hard gates. Added dwell time cannot compensate
for protected compromise, worse legitimate service or unsafe operator behavior.
A specific advantage requires its registered minimum worthwhile benefit with
adequate uncertainty, applicable non-inferiority gates, an independent rerun and
skeptical review. Otherwise retain INCONCLUSIVE/EXPERIMENTAL ONLY, DEMOTE or KILL.
Immediate block/static deception remains preferred when added complexity adds no
useful gain. No single aggregate score conceals a failure.

Synthetic mechanics never establish field or external-comparator superiority;
VM/container results never close hardware gates. Analysis cannot update canonical
runtime Outcome causality or effect support. Edge retains decision/enforcement,
Deception materializes only approved bounded environments, Knowledge advises,
Fabric describes, MIO reasons without action authority and Nexus UI stays read-only.
